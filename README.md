# Kronos — Timeless Design. Modern Performance.

Experience time like never before with Kronos — a stunning, immersive hourglass timer app that transforms how you focus, work, and live.

## ✨ Key Features

• **First-of-its-Kind Sensor Control** — Flip your phone into YAW to physically run and reset the hourglass.
• **Stand-Out Custom Skins** — Premium aesthetics including Classic Wood, Marble, Crystal, and Minimal Black.
• **Flexible Timing** — Set any duration from 1 minute to 12 hours.
• **Focus & Productivity Modes** — Built-in Pomodoro timer and streak tracking.
• **Ambient Tools** — Pair your timer with calming ambient sounds.
• **Offline First** — Works perfectly without the internet. No account required.
